# 蝶引速取

<p align="center"><img src="design/app-icon.png" alt="蝶引速取应用图标" width="160"></p>

> 蝶引一程，取件一码。

蝶引速取是一个非官方的 Android 取件辅助应用，把常用快递平台的身份码和待取包裹集中到同一个界面，减少在多个 App 之间来回切换。应用只在本机 WebView 中加载各平台官方页面，不提供账号服务，也不代理平台接口。

系统要求：Android 8.0 及以上。

## 支持平台

| 平台 | 身份码 | 待取包裹 | 说明 |
| --- | --- | --- | --- |
| 淘宝 | 支持 | 支持 | 在应用内查看 |
| 拼多多 | 支持 | 支持 | 可切换内嵌模式或跳转官方 App |
| 京东 | — | 支持 | 在应用内查看“我收到的”包裹 |
| 菜鸟 | 支持 | — | 通过菜鸟官方 App 的身份码页面直达 |

## 功能

- 底部三个板块：身份码、待取包裹、更多。
- 同一页面内展示多个平台的折叠卡片，可同时展开多个平台。
- 平台卡片展开、折叠和页面切换均带平滑过渡动画。
- 在展开的窗口内滑动只滚动该平台列表，在标题或窗口外滑动则滚动整个页面。
- 拼多多支持“内嵌显示”和“跳转官方 App”两种模式，避免同一账号在两个客户端之间互踢。
- 身份码与待取包裹可分别排序，并可显示或隐藏指定平台。
- 支持跟随系统、浅色和深色三种主题，可在“更多 → 显示”或右上角菜单切换。
- 可设置启动时默认打开身份码、待取包裹或更多页面，默认启动页为身份码，也可选择“上次停留”。
- 提供账号绑定管理、独立关于页，以及淘宝、拼多多、京东、小红书、美团、抖音订单快捷入口。
- 菜鸟快捷入口可跳过开屏广告，直接进入菜鸟首页。
- 支持手动检查更新，也可在关于页设置启动时自动检测。
- 记住上次停留的板块；淘宝、拼多多桌面快捷方式可直接打开身份码。

## 使用方法

1. 在“身份码”或“待取包裹”页点击平台名称展开卡片，再次点击收起。
2. 首次使用需在卡片内通过平台官方页面完成登录和必要验证；菜鸟身份码会直接打开菜鸟官方 App。
3. 拼多多卡片标题行的切换图标用于调整显示模式。未登录时首次展开也会先询问模式。
4. 京东待取卡片显示“我收到的”包裹；未登录时会先进入京东登录页。
5. “更多 → 订单快捷入口”可打开菜鸟、淘宝、拼多多、京东、小红书、美团、抖音的官方 App 页面；菜鸟会跳过开屏广告。
6. “更多 → 显示”可调整平台排序、切换主题，并设置启动时默认打开身份码、待取包裹或更多页面。
7. “更多 → 关于”可查看版本与项目地址；“检查更新”会与 GitHub 最新版本比对，关于页内也可开启启动时自动检测；页面同时提供反馈邮箱、版权与开源许可说明。
8. 卡片右侧提供登录状态和刷新按钮；登录管理位于“更多 → 账号绑定管理”。
9. 右上角菜单提供切换主题、排序和关于。

## 隐私与开源协议

- 仅申请网络权限。
- 不读取、不保存、不上传账号、密码、验证码、Cookie 或身份码内容。
- 登录状态只以“已登录 / 未登录”的布尔值缓存，仅用于界面显示，不作为凭据使用。
- 身份码和包裹信息只在应用内显示，不写入文件、不导出、不上传。
- 本地只保存界面偏好：上次停留的板块、主题偏好、默认页面、是否自动检测更新，以及各平台登录状态布尔值。
- 退出登录时按站点清理当前平台的 Cookie 和本地存储，不影响其他平台。
- 手动检查更新或开启启动时自动检测时，只访问 GitHub Releases 公共接口，不发送账号、设备标识或本地数据。
- 除检查更新访问 GitHub 公共接口外，没有自建服务器、统计 SDK、崩溃上报或埋点。
- 登录、验证码和包裹查询均由各平台官方页面执行。

## 项目结构

```
app/src/main/java/   原生界面与 WebView 容器

app/src/main/res/    界面、主题和图标资源
tests/               Java 与 Node.js 回归测试

```

## 自行构建

需要 JDK 17+（推荐 JDK 21）、Android SDK Platform 35、Build Tools 36.0.0 和 Node.js 24+。项目不依赖 Gradle。

```powershell
npm ci --ignore-scripts
.\build-android.ps1 -Configuration Debug -AndroidSdk "E:\AndroidSDK" -JavaHome "D:\Develop\jdk21"
```

Release 构建：

```powershell
.\build-android.ps1 -Configuration Release -AndroidSdk "E:\AndroidSDK" -JavaHome "D:\Develop\jdk21"
```

产物输出到 `dist`，同时复制到项目根目录；Release 构建会生成 SHA256 和 `release.json`。首次构建会在 `.local` 下生成调试签名，Release 沿用同一密钥，请自行备份。

## 兼容性与限制

- 淘宝、拼多多、京东的页面结构会随平台更新变化，适配失效时应用会停止对应操作并提示重试。
- 菜鸟身份码依赖已安装的菜鸟官方 App，未安装时会回退到官方网页。
- 非官方客户端，请自行确认是否符合所在地区法律及各平台服务条款。
